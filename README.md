# بريف دولاب

استبيان عملاء **وكالة دولاب الإبداعية** — نموذج واحد يغطي الهوية والتصميم، التسويق، والتقنية.

🔗 **الرابط:** https://doolab-sa.github.io/brief/

## البنية

| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحة |
| `questions.js` | كل الأسئلة (تعديل الأسئلة يتم من هنا فقط) |
| `app.js` | محرّك الاستبيان: التنقّل، الحفظ التلقائي، الإرسال |
| `styles.css` | التصميم وهوية دولاب |
| `config.js` | رابط نقطة الاستقبال |
| `assets/` | الشعار، الأيقونة، خطوط Montserrat Arabic |

## كيف يشتغل

العميل يختار الخدمة (أو أكثر) → يجاوب الأسئلة المشتركة مرة وحدة → ثم أسئلة كل خدمة → عند الإرسال يروح كل قسم لتبويبه الخاص في Google Sheet، مربوطين بـ «معرّف الطلب».

> كود الخادم (Google Apps Script) محفوظ خارج هذا المستودع لأنه يحتوي بيانات حسّاسة.
